# Background pattern sources

## Hunminjeongeum Haerye

`hunminjeongeum-haerye-source.jpg` is a 960px Wikimedia Commons rendering of **Hunminjeongeum Haerye 10**, a 1446 Joseon government work sourced there from the Kyujanggak Institute for Korean Studies.

Source page: `https://commons.wikimedia.org/wiki/File:Hunminjeongeum_Haerye_10.jpg`

Wikimedia Commons marks the file as public domain in both the United States and the Republic of Korea.

`hunminjeongeum-haerye-tile.svg` is the site's presentation tile: it only desaturates, lowers opacity, scales, and tilts the source image for the dark-mode ambient background.
