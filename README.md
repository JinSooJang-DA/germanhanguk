# 🇩🇪 German-Hanguk

> A helpful and informative community-driven platform created for Koreans living in Germany to share valuable tips, local insights, and daily life experiences.

---

## 💡 About the Project

This project is built as a hands-on practice ground to master **Next.js** and **Database (Supabase)** integration, exploring full-stack features, data handling, and backend communication.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (React)
- **Database & Backend**: Supabase (PostgreSQL)
- **Languages**: TypeScript, HTML5, CSS3
- **Deployment**: Vercel

---

## ✨ Key Features

- **Community Info Sharing**: Designed to help Koreans navigate life in Germany by sharing useful resources and local information.
- **Database Operations**: Handles data storage, retrieval, and management through practical integration with Supabase.
- **Responsive UI**: Optimized for a seamless experience across mobile and desktop devices.
