## 유학생 커뮤니티 조사 → 제품 방향
DAAD·Deutsches Studierendenwerk 자료에서 반복되는 문제는 비자·행정, 주거, 생활비/재정, 건강보험, 독일어, 개인적 연결, 학업과 일의 병행, 졸업 후 취업 전환이다. 특히 국제학생은 공식 지원창구가 있어도 비공식 네트워크·소셜미디어를 많이 사용한다. GermanHanguk은 이 간극을 공략할 수 있다.

### 커뮤니티에 반영할 구조
- `독일 유학생 되기 / 유학 준비`: 출국 전부터 입국·등록까지 질문과 경험.
- `유학생 일기 / 경험 공유`: 정보글이 아닌 생활기록도 축적해 재방문 이유를 만든다.
- `학교생활 / 수업 / 시험`: Prüfungsordnung, 과제, 교수·세미나, 학업 적응.
- `비자 / 외국인청`, `집구하기 / WG / 기숙사`, `보험 / 재정증명 / 생활비`.
- `알바 / Werkstudent / 인턴`, `졸업 / 취업 / 진로`로 입학 이후까지 이어간다.

이번 코드에서는 기존 `sub_category` 구조를 확장해 위 주제를 실제 글쓰기 선택지로 넣고, 유학·교육 게시판에 `유학생 코너` 필터와 `유학생 일기 쓰기` 진입점을 추가했다. 기존 DB 스키마를 바꾸지 않아 위험이 낮고, 기존 글과도 호환된다.

### 이후 확장 후보
- 학교/도시 태그: Universität·Hochschule 단위 검색과 지역 결합.
