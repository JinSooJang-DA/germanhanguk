# GermanHanguk 커뮤니티 성장 시스템 v1

## 목표
점수 경쟁이 아니라 좋은 글, 대화, 정보 습득과 도움을 자연스럽게 보상한다. 국적과 무관한 커뮤니티 등급과 선택형 독일생활 기간을 분리해 향후 Tandem/문화행사 확장을 막지 않는다.

## 공개 모델
- 등급: 🌱 독일 새싹 → 🧭 정착 탐험가 → 🏡 정착러 → ⭐ 동네고수 → 👑 생활 마스터
- 독일생활 기간: 시작일 원본은 비공개. 사용자가 허용할 때만 `독일생활 5년차` 같은 계산값 표시.
- 프로필 수치: 활동 / 지식 / 소통 / 도움. 사용자가 공개 여부 선택.
- 게시글·댓글에서는 등급과 생활기간만 작게 표시하고 상세 수치는 프로필에서만 노출.

## v1 보상
- 글 작성: 경험치 +3, 활동 +3
- 댓글/답글 작성: 경험치 +1, 활동 +1, 소통 +1
- 생활가이드 최초 의미 있는 읽기: 경험치 +1, 지식 +1 (가이드별 계정당 1회)
- 내 글이 다른 사용자에게 추천받음: 경험치 +1, 도움 +1

## 어뷰징 원칙
클라이언트가 점수를 직접 수정할 수 없고 DB 트리거/보안 RPC만 점수를 만든다. 같은 원천 행동은 이벤트 원장 unique key로 한 번만 반영한다. 자기 글 추천은 도움 점수에서 제외한다. 삭제/신고 차감은 운영 데이터가 쌓인 뒤 v2에서 결정한다.

## 개인정보/표시 기본값
- 등급 표시: 기본 ON
- 독일생활 기간: 기본 OFF
- 상세 활동 수치: 기본 ON
- `germany_since` 원본 날짜는 공개 프로필 화면이나 게시글 API에서 직접 표시하지 않는다.
- 향후 언어/관심사/Tandem 가능 여부는 별도 프로필 확장으로 추가한다.

## 등급 기준
- 0: 독일 새싹
- 20: 정착 탐험가
- 80: 정착러
- 200: 동네고수
- 500: 생활 마스터

초기 기준은 운영 중 활동 분포를 보고 조정한다. 과거 게시글/댓글에는 소급 점수를 주지 않는다. 테스트·수입 데이터와 실제 활동을 구분하기 어렵기 때문이다.

## 구현 단계
1. DB 스키마/이벤트 원장/트리거/RPC
2. 마이페이지에서 독일 시작일 및 공개 설정
3. 공개 프로필에 등급·선택형 생활기간·수치 표시
4. 게시글/댓글 닉네임 옆에 선택형 미니 배지
5. 실제 읽기 신호를 정한 뒤 가이드 지식 보상 연결
6. v2에서 `도움됐어요`, 분야 배지, Tandem/행사 활동 연결

## v1 안전장치 확정
- 일일 점수 반영 상한: 글 5개, 댓글/답글 20개, 받은 추천 30개, 가이드 10개.
- 추천을 취소했다 다시 눌러도 `게시글ID + 추천자ID`가 동일 원천으로 처리되어 도움 점수를 다시 받을 수 없다.
- 가이드 지식 보상은 페이지 진입만으로 주지 않는다. 로그인 상태에서 20초 이상 머물고 본문의 60% 이상 진행했을 때 최초 1회만 요청한다.
- 독일 거주 시작일은 공개 `profiles`가 아니라 본인만 읽고 수정 가능한 `profile_private_details`에 저장한다.
- 공개 프로필은 보안 RPC가 공개설정을 적용한 등급/연차/수치만 반환하며, 실제 거주 시작일과 비공개 점수는 반환하지 않는다.

## 커뮤니티 미니 배지 준비 상태
- 게시판 목록, 게시글 작성자, 댓글/답글에 등급·선택형 독일생활 기간을 작게 표시하도록 연결했다.
- 작성자별 개별 조회(N+1) 대신 `get_public_community_identities(uuid[])` 배치 RPC를 사용한다.
- 배치 RPC도 실제 시작일이나 비공개 점수는 반환하지 않는다.
- 기능 플래그가 꺼져 있는 동안 RPC 호출과 배지 렌더링은 모두 비활성 상태다.
